# CryptoCurrency

## 🖼️ Dashboard Preview

![Dashboard](aayushitejwani7-png)

This project presents an interactive Cryptocurrency Market Analysis Dashboard built to analyze trends, trading volumes, and market capitalization across major cryptocurrencies.

The dashboard provides meaningful insights into the crypto market, helping users understand price trends, market dominance, and trading activity over time.

🎯 Key Features
📈 Market Capitalization Trend Over Time
💰 Trading Volume by Cryptocurrency
🪙 Market Cap Comparison Across Coins

📊 Key KPIs:
Total Trading Volume: 112.08T
Highest Price Recorded: 64.86K
Average Market Cap: 15.43B
Lowest Price Recorded: 7.93E-5

🔍 Interactive Filters:
Cryptocurrency selection (Bitcoin, Ethereum, etc.)
Year-wise filtering (2013–2021)
🛠️ Tools & Technologies Used
Power BI – Dashboard creation & visualization
Excel / CSV – Data preprocessing
Data Cleaning Techniques – Handling missing values, formatting

📂 Dataset Description
The dataset contains historical cryptocurrency data including:
Date
Open, High, Low, Close prices
Trading Volume
Market Capitalization
Cryptocurrency Name & Symbol

📌 Dashboard Insights
Bitcoin dominates market capitalization compared to other cryptocurrencies
Significant market growth observed post-2017
Trading volume is highest for stablecoins like Tether
Market shows high volatility with sharp peaks and drops
